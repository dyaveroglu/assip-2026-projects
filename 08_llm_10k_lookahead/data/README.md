# Data for Project 08 — Is the LLM Reading the 10-K or Remembering the Stock?

**The `data/` folder is intentionally not published.** The analysis combines public SEC
EDGAR 10-K text with return data licensed from Wharton Research Data Services (WRDS), which
may not be redistributed, and with locally generated large-language-model scores. This README
documents every source so the pipeline can be reproduced by anyone with the appropriate WRDS
subscription and GPU access.

## Sources
| File (local, not shipped) | Source | Key fields |
|---|---|---|
| `raw/INDEX_edgar.csv` | SEC EDGAR full-index (public) + a reusable Item-1A archive on GMU Hopper (`/groups/LGAO/edgar_archive`) | CIK, accession, form, filing date, path to pre-extracted Item 1A |
| `raw/crsp_monthly.csv` | CRSP `crsp.msf_v2` via WRDS (monthly, through 2025-12) | permno, date, ret, ticker |
| `raw/ff_monthly.csv` | Fama–French factors (`ff.factors_monthly`) via WRDS | mktrf, rf (market factor + risk-free) |
| `interim/sample_final.csv` | Compustat `comp.company` + CRSP `crsp.ccmxpf_lnkhist` (CIK→permno link) via WRDS | filing metadata, gvkey/permno, pre/post window, forward BHAR (3/6/12m) |
| `raw/rf/{id}.txt` | Item-1A (Risk Factors) plain text extracted from the EDGAR archive | raw risk-factor text |
| `interim/anon/{id}.txt` | Automated anonymizer (this repo, `07_fetch_anon.py`) | machine-redacted risk-factor text |
| `interim/llm_scores.csv` | Llama-4-Scout (109B) run locally via Ollama on the GMU Hopper GPU cluster (`score_ollama.py` / `10_llm_score.py`) | raw & anonymized 0–100 downside-risk scores per filing |
| `interim/anon_stats.csv` | Automated anonymizer diagnostics | redaction counts, name leaks, raw char length |

Public inputs (redistributable): the SEC EDGAR text is public; the CRSP/WRDS return data and
the CRSP-Compustat link are licensed and are **not** shipped.

## Reserved for the student (not built by the automated pipeline)
The hand-built **anonymization gold standard** and the **human blind-identification /
leakage** measurement (`interim/gold_anon/{id}.txt`, `interim/gold_redactions.csv`,
`interim/blind_test.csv`) are the student's pivotal manual contribution; see
`STUDENT_TASKS.md`. The automated `anon/` floor is a lower bound on redaction, not the gold
standard, and none of the extension tables use a hand-anonymized text or a human
identifiability judgment.

## Reproduce
```bash
python code/00_link_sample.py   # filter EDGAR index, define pre/post windows, CIK→permno link, sample
python code/05_returns.py       # CRSP monthly + FF market → forward BHAR (3/6/12m)
python code/07_fetch_anon.py    # fetch Item-1A text; automated anonymizer + redaction stats
python code/10_llm_score.py     # Llama-4-Scout raw & anon scoring (Ollama on Hopper)
python code/20_panel.py         # merge scores + returns → data/processed/panel.csv
python code/30_regressions.py   # placebo regressions → output/tables/t1..t6*.csv
python code/35_tables_tex.py    # booktabs LaTeX tables from the CSVs
python code/40_figures.py       # figures (agreement, slope bars, pre-cutoff scatter)
python code/50_extensions.py    # heterogeneity, composition matching, randomization inference, power → t7..t10 + fig4
cd paper && tectonic main.tex   # compiles the paper
```
Everything downstream of the WRDS pull and the LLM scoring (the panel, all tables, all
figures, the paper) is fully determined by the committed `code/`. The `output/tables/*.csv` in
the repo are the exact numbers behind every table in the paper; `code/45_fill_paper.py`
generates the base-paper prose from those CSVs (note: `paper/main.tex` has since been extended
by hand for the journal-track version and updated to the Llama-4-Scout model, so it is not
regenerated by `45_fill_paper.py`).
